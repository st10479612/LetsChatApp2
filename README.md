Features User Registration: Collects username, password, and contact details.

Strict Validation Logic:

Username: Must be no more than 5 characters long and include an underscore (_).

Password: Must contain at least 8 characters, including one uppercase letter, one lowercase letter, one number, and one special character.

Phone Number: Validates specifically for South African formats (starts with +27 and is exactly 12 characters long).

Interactive Console: Provides real-time error feedback if validation fails.

Authentication: Verifies login details against registered credentials.

Built With Java - Programming language.

Maven - Dependency management.

JUnit - Unit testing framework for validation logic.

How to Run Clone the repository:

Bash git clone Navigate to the directory:https://github.com/st10479612/LetsChatApp/tree/main

Bash cd LetsChatApp Compile and Run: Open the project in NetBeans or IntelliJ and run the Chat_app2.java file.

Unit Testing This project includes unit tests to ensure all validation methods work as expected. To run the tests:

Right-click the project in NetBeans.

Select Test.

Verify the assertTrue and assertFalse results for username, password, and phone formatting.
